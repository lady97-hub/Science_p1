좋은 약속의 예시

  • 컴퓨터 사용 시간을 서로 배려하여 양보해요.

  • 친구나 나의 개인정보를 AI 질문창에 입력하지 않아요.

사회·도덕·국어 프로젝트 학습 결과물

깃허브(GitHub Pages)에 이 웹앱 무료 배포하기

학생들과 만든 완성된 앱을 인터넷에 공개하여 언제 어디서나 접속할 수 있습니다.

1단계

소스 코드 저장

이 웹앱 파일의 전체 코드를 복사하여 내 컴퓨터에 index.html 이름으로 저장합니다.

2단계

GitHub 저장소 생성

GitHub 로그인 후 New Repository를 누르고, 이름을 ai-rules-app 으로 입력 후 만듭니다.

3단계

Pages 활성화

index.html 업로드 후 Settings > Pages > Branch: main 선택 후 Save를 클릭합니다.

현재 웹앱 HTML 파일 다운로드 / 복사

다운로드한 index.html 파일을 깃허브 Repository의 [Add file] -> [Upload files]로 업로드하면 약 1~2분 후 https://사용자ID.github.io/ai-rules-app 형태의 학급 웹주소가 생성됩니다.

선생님 팁 (Classroom Tip)

· 데이터는 학생들의 브라우저(LocalStorage)에 저장되므로, 학급 전체 모니터링 시에는 선생님 컴퓨터 화면을 전자칠판에 띄워 함께 투표를 진행하는 방식을 권장합니다.
